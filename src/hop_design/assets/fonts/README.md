# Portable scientific report font

DejaVu Sans 2.37 is distributed unchanged with its LICENSE from the
[official 2.37 release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).
The [license](https://dejavu-fonts.github.io/License.html) permits redistribution
with its notices. The font supplies primes, arrows and pairing symbols missing
from the PDF encoder's smaller default font. Export checks glyph coverage before
publication; it does not depend on installed system fonts.

Molecular label placement reserves the larger of the SVG's Helvetica metrics and
this embedded PDF face. PDF encoding and placement share the font registration,
so a label that fits in the browser cannot become wider than its reserved box
when exported with DejaVu Sans.
