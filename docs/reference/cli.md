# CLI reference

Start with the [worked discovery example](../guides/discover-designs.md). The
signatures below use placeholders such as `DNA`, `DESIGNS` and `NEW`. Replace
them with your sequence and paths; output directories must be new.

Choose commands by the input you have and the result you need:

- [Design discovery and variant commands](cli/design-and-variant-commands.md)
  resolve or continue complete-design discovery, inspect conditional variants,
  evaluate molecular edits and exact families, and compile substrate spaces or
  individual designs.
- [Construction and comparison commands](cli/construction-and-comparison-commands.md)
  navigate verified bundles, prepare requests, continue explicit local choices,
  compare families, run resumable surveys and retrieve selected preparations.

The [Python API](python-api.md) and
[external artifact interface](external-artifacts.md) describe the corresponding
programmatic operations and portable records.
