# Workflow view contracts

Use these contracts to choose a molecular projection and understand which
verified record supplies its sequences, coordinates, contacts and processing
steps.

- [Component and local construction views](view-contracts/component-and-local-views.md)
  defines `WorkflowView`, rendering examples, local feasibility tables, local
  measurements and selected source-partition certificates.
- [Complete preparation views and inspection](view-contracts/complete-preparation-views.md)
  defines portraits, summaries, navigation, trajectories and molecular-state
  inspection, with the browser controls and event marks used to read them.

The [ontology](../language/ontology.md) defines the underlying molecular
objects. The [parameter registry](molecular-parameters.md) defines their units
and coordinate boundaries.
