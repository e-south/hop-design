# Grouped scaffold comparisons

Let users require different scaffold products, each made through several methods,
without translating their intended comparison into local construction identities.

## Delivery checklist

- [x] Strict versioned groups; identical stage products within each group and
  distinct products between groups; unchanged v1 interpretation.
- [x] Preview, bounded assessment, explicit selection and relocated retrieval over
  verified complete options; retained missing, rejected and unexamined members.
- [x] Generated scaffold-by-method molecular sheets; fresh CLI/API execution.
- [x] Verified prior-product reference per group and explicit permitted changes.
- [x] Exact resulting loop words propagated through bounded discovery and complete
  construction verification, with orientation and length consistency.
- [x] Early endpoint/material-role conflicts, conditional retrieval guidance and
  molecule-located enzyme failure diagnostics.
- [x] Public journey dogfooding, rendered inspection, strict preflight and full
  verification including installed-wheel parity.

## Acceptance and ownership

The first slice requires four preparations with two exact released products:
two loop sizes crossed with two methods. Each row preserves the product across
methods; rows differ. The same records must continue to fail the incompatible
all-distinct and all-identical v1 requests. Changing comparison stage reassesses
identity. Preserve bounded coverage, replay and explicit membership selection.

HOP owns generic comparison contracts and exports. Caller studies own experimental
questions, evaluation records and interpretation. No new chemistry, exposed-end
hairpin capability, automatic winner, dashboard or biological-performance claim
is included. Existing evidence packets remain immutable.

## Validation

Begin each behavior with a failing public-seam test. Cover malformed partitions,
changed stage, order independence, incomplete assignment and molecular coverage,
missing methods, altered records, fresh execution and relocated retrieval.
Inspect vector sheets at print size and run `bash scripts/agent-preflight --strict`
and `bash scripts/agent-verify` before delivery.

## Delivered verification

The full local endpoint passes: 2,078 tests with 91.43% coverage, public-documentation
execution, dependency audit and recursive source/installed-wheel parity. The
shipped grouped and exact-loop examples are included in that parity check.
Repository organization limits remain unchanged. Shared diagnostic text lives in
`export/construction/handoff`; foldback enzyme-binding placement lives in the
existing orientation module, separate from sequence-domain solving. Run the
repository-structure checks with focused tests before the full endpoint.
