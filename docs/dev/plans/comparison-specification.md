# Molecular comparison specifications

Help users obtain meaningful substrate sets or alternative preparations of one
exact product without manually translating intent into local construction IDs.
The public journey is define comparison → discover complete options → assess
membership → explicitly select → retrieve preparations.

## Delivery checklist

- [x] Comparison brief and preview: distinguish permitted dimensions from required
  members; disclose inherited domains, exclusions and fixed direct-hairpin arms.
- [x] Assessment over verified options: stage-specific distinctness or equality,
  shared molecular controls, material permissions, bounded reference-free groups,
  scoped missing/failed/unexamined outcomes; no automatic membership selection.
- [x] Direct execution and named retrieval: reuse discovery; retain all requested
  members; CLI/API equivalence and portable selections.
- [x] Independent adapter-ligated hairpin endpoint: prove and validate the existing
  processing prefix; omit downstream materials/events; preserve recovery limits.
- [x] Generated substrate and preparation-alternative sheets: verified molecules,
  countable details, stage identity, missing members, consolidated oligos.
- [x] Dogfood and verification: crossed dimensions, exact-product methods, missing
  loop values, fixed materials, tight budgets, hairpin retrieval; rendered review,
  strict preflight and full verification including installed-wheel parity.

## First executor contract

The delivery began with preview and assessment over existing verified discovery
packets, before changes to molecular execution. Four distinct hairpins may yield
two distinct inserts; they must not satisfy a four-distinct-insert requirement. Alternative
methods may satisfy exact endpoint identity while retaining distinct preparations.
Every required member remains visible, including values excluded by permissions.

Use failing public-seam tests before each behavior change. Preserve strict input
schemas, one molecular authority, create-only publication, semantic replay and
bounded enumeration. Grouping limits are separate from molecular search limits.
No inferred global impossibility follows from missing evaluated options.

## Scope and ownership

HOP owns generic contracts, execution, comparison and exports. Caller studies own
their questions, dogfooding and interpretation; manuscript selection is separate.
Exclude dashboards, automatic winners, biological-performance prediction, new
reaction chemistry and automatic design of direct-hairpin basal arms. The new
hairpin endpoint needs independent molecular validation, not a relabeled drawing.

## Validation

Target public API/CLI tests, strict/negative schema tests, altered-packet rejection,
stage identity, order-independent grouping, tight budgets and relocated retrieval.
Inspect generated vector figures at print size. Finish with
`bash scripts/agent-preflight --strict` and `bash scripts/agent-verify`.
