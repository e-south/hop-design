# Browser inspection

Measure opening the atlas, hovering, pinning and scrolling as separate tasks.
Pinning projects the preparation's exact states, comparison and construction cost,
then draws its hairpin and loads visible processing steps. Scrolling requests
newly visible scenes; **Full figure** explicitly opens the complete route.
Deferring artwork does not remove molecular verification. Public `atlas()` and
CLI atlas exports still produce the complete route.

Choose the part of the interaction you need to investigate:

- [Interaction and loading](inspection/interaction.md): latest-target behavior,
  coherent commits, resizing, browser checks and visible errors.
- [Scene drawing and rendering](inspection/rendering.md): requested phases,
  preview-worker boundaries, cache limits and saved rendering policies.
- [Cohorts and queries](inspection/cohort-and-query.md): admitted query facts,
  neighbor ranking, dense-map drawing and color scales.

Closing the inspection server removes temporary previews and plots. Deliberately
requested material exports remain in the inspection output directory. Use the
[verification boundary](verification.md#choose-the-verification-boundary) that
matches the changed responsibility.
