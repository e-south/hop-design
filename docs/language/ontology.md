# HOP Design ontology

This reference defines HOP's molecular objects and the records that describe
them. An input states what the caller permits; a result records what HOP
resolved and checked. Saved views and files present those results.

Choose the vocabulary for the question you are reading:

- [Molecular meaning and construction search](ontology/molecular-meaning-and-search.md)
  explains structural features, products, preparations, local realizations and
  conditional choices.
- [Typed molecular records and processing](ontology/molecular-records-and-processing.md)
  defines design inputs, compiled products, catalog searches, states, materials,
  methods and verification records.

For units and coordinate boundaries, use the
[parameter registry](../reference/molecular-parameters.md). For relationships
between records, use [relationships and invariants](relationships-and-invariants.md).
