# Molecular comparison briefs

An allowed scaffold interval does not require all its values to be represented.
`hop.comparison-brief/v1` embeds the existing discovery request and separately
declares named required members, comparison purpose, shared hairpin properties,
preserved material roles and bounded assignment evaluation. Its discovery stage
defines where exact physical identity matters. No second molecular evaluator or
new sequence-design authority is introduced.

`models.construction.comparisons` owns strict authoring. The corresponding design
package owns preview, replay-bound assessment, orchestration and explicit
retrieval. Export code renders verified records. The preview discloses domain
holes and fixed direct-hairpin arms; conflicts require explicit edits rather than
relaxing or removing members.

Assessment requires a semantically verified discovery with the same normalized
molecular request, permissions and bounds. Only the comparison-stage projection
may differ. Existing portrait facts supply shared controls; existing physical
identity supplies exact stage equality. A distinct-substrate set requires a
different stage identity for every member. Preparation alternatives require one
stage identity and distinct preparation identities. Exact material IDs, including
sequence and chemistry, enforce cross-member preservation requirements.

Required member names and option labels determine neutral, deterministic
assignment order. No first completed member becomes an implicit reference.
`max_group_evaluations` bounds examined assignments and `max_sets` bounds returned
sets. Unexamined assignments, local search coverage, unexamined continuations,
examined failures and missing member slots remain separate facts. Absence from
this pool never proves global impossibility. An empty roster requests discovery
without imposing membership obligations or inventing a set.

The portable assessment embeds its discovery. Retrieval captures its inventory,
replays molecular authorities and recomputes assessment before admitting a
displayed set label. Selection is explicit; an ordinary construction set supplies
named preparations, exact oligos and relocation-safe replay. A resealed changed
membership is rejected. Comparison results are derived projections, never a
replacement for complete construction authority.

Schemas are new, strict and have no permissive aliases. Existing discovery and
construction-set schemas retain their meanings. The independently validated adapter-ligated
endpoint is specified in [ADR 0045](0045-adapter-ligated-hairpin-endpoint.md);
viewing an intermediate remains distinct from requesting that endpoint.
