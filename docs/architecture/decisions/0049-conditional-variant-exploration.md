# Conditional exploration over complete products

The user asks what can vary in a neighborhood while specified properties remain
fixed. Independent local domains cannot answer this: coupled processing may reject
a combination or change retained sequence elsewhere. Query a finite admitted set
of complete preparations, projecting supported neighborhood variants from whole
products at a named stage. Do not construct products in the query layer.

`models/construction/variants/query.py` owns the strict stage, neighborhood, pins,
fixed reference and controls. `design/construction/variants/` separates source
admission, immutable facts, filtering, projection and retrieval. Existing discovery
replay, molecular identity, regional ancestry and stage-control assessment remain
the authorities. `comparisons/controls.py` supplies the same regional context to
both preserved-property checks and variant projection. Missing ancestry stays
unassessed.

Pins admit a union of variants within each neighborhood and an intersection across
neighborhoods. Replacement alternatives omit only the current focus pin. The
compatible product list enforces every pin. Controls compare every candidate to
the explicitly named reference at their own stage, independent of the current
focus or preview. Exact stage identity groups products while retaining distinct
preparations. Filtering never commits a product or chooses a best preparation.

One `ScaffoldExploration` receipt captures a verified result and immutable
serialized molecular facts. Warm queries perform no file admission, search,
replay or report generation. The caller owns receipt lifetime; there is no global
or modification-time cache. Report export and molecular projection are separate.
Retrieval captures and re-admits the source, re-derives the choices, checks full
active membership, and delegates ordinary portable-set assembly to its existing
owner. Product identity and singleton controls are checked against the exploration
reference; multi-member regional controls also travel in `set.json`.

The result-manifest digest binds the query to the exact saved packet. Query and
decision records remain provenance, while member bundles establish molecular
authority. Rehashing altered presentation data does not replace replay. Portable
set replay verifies its molecules independently; repeating the original exploration
requires the original result packet and query.

The loopback viewer uses this same API and retains host/origin/token protections.
Its one molecular preview is separate from fixed reference and explicit set
membership. Search expansion and exact authored edits remain separate operations.
Complete exclusions, failed examined continuations, local exhaustion and incomplete
coverage remain separate. Absence is not global infeasibility, and unpermitted
possibilities are untested.

Verification lives in `test_scaffold_variant_query.py`,
`test_scaffold_variant_exploration.py`, `test_variant_editor.py` and the public
molecular-editing recipes. The measured 15-option recipe separates admission,
100 deterministic warm queries and reverified retrieval; warm p95 target is 100 ms.

## Linked choice-space projection

`variants/choice_space.py` projects only the active query's admitted preparations
into named, stage-qualified coordinates. Outside-loop background identity reuses
the assessed regional sequence, contacts and termini; it is independent of the
loop and method names. Unknown regional facts remain unassessed. Exact product
groups retain all preparation identities. This additive `choice_space` view is
available through the existing query facade and CLI; no new request or solver is
introduced. Saved choices remain replay-strict and must be regenerated if their
derived presentation schema differs.

The browser separates a pure coordinate filter, SVG layout and event adapter.
View filters intersect whole paths and cannot join regional parts. They neither
mutate the molecular query nor serve as required-set obligations. Explicit query
edits clear these transient filters. Previewing delegates existing atlas navigation
and preserves its camera, processing phase and fixed reference. A coincident path
does not choose an arbitrary preparation. Unit, HTTP and browser-model checks
cover product multiplicity, missing facts, OR/AND filtering, numeric spacing and
the absence of fabricated combinations.

## Parameterized envelope projection

`models/construction/variants/parameters.py` owns stage-qualified measurement and
selection contracts. Discovery compiles supported restrictions into joint local
requests and checks remaining achieved properties after completion. Variant
projection supplies declared domains, bounded coverage and achieved coordinates.
The browser consumes these facts; it contains no separate molecular solver.

Complete paths retain the admitted pool with an explicit eligibility flag. Local
support comes only from replayed local realization records and stops before
unassessed coordinates. Neither marginal domains nor partial paths establish a
complete Cartesian product. Counts omit only the axis being considered while
retaining the other constraints. Explicit further evaluation stores parent and
additional evidence in an immutable packet and replays both on admission.

Atlas measurement locations trace exact reference addresses through recorded
material ancestry, including copies. Camera movement, parameter selection,
preparation preview and additional evaluation remain distinct operations.
