# Explicit comparison controls

A scaffold family can require `non_loop_sequences`, `regional_contacts` and
`regional_joins` through its existing `hold` / `shared_properties` vocabulary.
This extends the accepted property values without changing prior request bytes
or any molecular authority. Unknown properties still reject. A complete member
may disagree with the family and remains recorded, but is ineligible for its
shared display. Set selection rejects a declared disagreement before publication;
a report cannot use a weaker set request to bypass the family's requirements.

The comparison and admission paths use one region-local fact derivation over the
verified hairpin architecture. Non-loop sequences include all eight non-loop
regions, including terminal tracts. Contacts retain primary-region offsets,
literal bases and contact classes. Joins retain bond boundaries within all nine
regions, including the loop. Each new property binds the hairpin stage. Absolute
coordinate movement does not itself violate a regional control. Material roles
and later copied products remain separately compared.

`hop.construction-set-summary/v2` and set identity version 2 bind the explicit
controls and their assessments. `hop.construction-family-report/v3` reports
family-wide and selected-set assessments separately, each with its own reference
and membership. Outcomes are required-and-verified, observed agreement,
difference or not-assessed; differing and unassessed member lists remain explicit.
A missing complete molecule cannot count as agreement. Requirements restrict
admission, not the solver's coverage or discovery order. A declared requirement
may have no matching family in the evaluated pool.

A single selected molecule has no between-member comparison: all agreement
assessments are `not_assessed`, while achieved properties remain available.
The report preserves the selected set's `compared_properties` as declared intent,
distinct from observed differences. A choice's `selection_name` links caller
aliases to its family member without changing either identity.

Old saved family outcomes remain verified under their recorded property roster;
no new property is silently added to their shared-reference record. Old selected
set summaries and report projections remain historical outputs. Regenerating
these derived views uses the unchanged molecular authorities and emits the new
schemas. There is no alias that relabels an old summary as a new one.

Reconciliation may record `preferred_loop_nt`. This is a caller-declared reason
for an already explicit local selection, not a selection algorithm. It must
match every complete target hairpin and is rechecked when admitting the revision.
Absent preference remains absent. The recovery projection reads available local
witnesses and the selected ID from verified authority; those witnesses are not
depicted as complete preparations. Original outcomes remain in the parent capture.

The report opens with preparations, order specifications and membership. Technical
accounting follows those actions. Static plates annotate one reference, align
countable loop crops, state the scope of shared agreement once and combine a
failed preparation with its authored alternative. Recovery uses a separate
decision view. Rendering consumes admitted facts and performs no new search.

HOP owns these reusable contracts and renderers. Callers own the scientific
comparison, participant tasks, experimental observations, and destination
checks. Unfamiliar-user evaluation remains separate from software verification.
