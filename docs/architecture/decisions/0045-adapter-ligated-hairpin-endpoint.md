# Independently validated adapter-ligated hairpin

`adapter_ligated_hairpin` requests the existing basal-open processing prefix as
an endpoint. It is not a renamed intermediate from an insert request. Its source
requires basal authority and a separate `materialization.adapter_ligation`
policy, and forbids endpoint PCR auxiliaries and release specifications. Direct
hairpins retain their fixed-arm contract; duplex endpoints retain their copying
and release requirements.

The source-to-adapter-ligation program is built once and reused by PCR routes.
The independent endpoint evaluates adapter resolution, molecular pairing,
provisioning and source partition without evaluating downstream primers. Replay
requires the exact eight states and seven transitions, a continuous hairpin
strand, recorded contacts and joins, terminal chemistry and design encoding.
Material functions and dispositions are projected from that actual endpoint.
Downstream copying, fates and cohesive ends are absent.

The new optional material field is excluded when absent, preserving existing
serialized requests. Complete-authority semantic replay, producer identity and
strict model validation still bind the endpoint; no drawing or summary grants
molecular authority. Reports label this endpoint explicitly and retain reaction
and fragment-recovery conditions. Cleavage and ligation chemistry are
unchanged; exposed-end hairpins remain unsupported.
