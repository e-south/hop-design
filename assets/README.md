# README artwork

[`hop-design-banner.svg`](hop-design-banner.svg) is the editable banner source.
[`hop-design-banner.png`](hop-design-banner.png) is its 2× raster export
(2560 × 360 pixels), used by the main README so its typography renders
consistently in image viewers. Keep both files together when changing the art.

The SVG embeds IBM Plex Sans under the accompanying
[Open Font License](fonts/OFL-IBM-Plex-Sans.txt); the heading uses Georgia.
Render with those fonts loaded, preserve the transparent rounded corners, and
inspect the result at README width. The molecule and oligo symbols are
schematic, not sequence-length or reaction-efficiency claims.
